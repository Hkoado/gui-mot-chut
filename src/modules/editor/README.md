# Editor extension boundary — phase 1

No editor, uploads, database or customer dashboard is implemented. Phase-one content changes are performed by the studio.

Future draft contract to consider: `templateId`, allow-listed `fontKey`, `themeKey`, image asset references and structured text fields. Validate each field against capabilities of the selected template. Do not accept raw HTML/CSS, arbitrary user fonts, or public image uploads without a separately designed storage, moderation, privacy and authorization policy. Theme presets for customer websites remain distinct from this landing-page theme.
